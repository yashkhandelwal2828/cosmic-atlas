# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) Code of Conduct, version 2.1.

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by opening a GitHub issue marked confidential if possible, or via the repository security advisory channel described in [SECURITY.md](SECURITY.md).
