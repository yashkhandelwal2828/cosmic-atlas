# Assets agent note — `public/textures/raw8k`

The directory holds real Solar System Scope (SSS) source textures, not placeholders: `file` identifies thirteen valid baseline JPEGs (`2k_neptune.jpg`, `2k_uranus.jpg`, `4k_venus_atmosphere.jpg`, `8k_earth_clouds.jpg`, `8k_earth_daymap.jpg`, `8k_earth_nightmap.jpg`, `8k_jupiter.jpg`, `8k_mars.jpg`, `8k_mercury.jpg`, `8k_saturn.jpg`, `8k_stars_milky_way.jpg`, `8k_sun.jpg`, `8k_venus_surface.jpg`) at documented SSS equirectangular sizes (2K 2048×1024, 4K 4096×2048, 8K 8192×4096) with multi‑MB payloads and Exif metadata (several stamped Adobe Photoshop CC 2014), plus companion TIFF normal/specular maps, one PNG ring alpha (`8k_saturn_ring_alpha.png`), and a leftover `cookies.txt` for `www.solarsystemscope.com` that further confirms download provenance under CC BY 4.0.
